Adaptive Zero-Trust Network Observer (AZT_NO) is a cybersecurity system designed to monitor, analyze, and classify network and web activity in real-time using a Zero-Trust architecture combined with Machine Learning.

The system continuously inspects domains, network packets, and processes to detect phishing, malicious behavior, and anomalies, ensuring that no entity is trusted by default.

🚀 Features
🔍 Real-time Packet Monitoring
Captures network packets using Scapy
Extracts features like IP, protocol, and traffic patterns
🌐 Domain Analysis Engine
Detects suspicious domains using feature-based ML models
Identifies phishing URLs
🧠 Multi-layer Machine Learning
Domain reputation model
Behavioral anomaly detection model
Extensible architecture for additional layers
🔐 Zero-Trust Enforcement
No implicit trust for any domain or process
Continuous verification of activity
📊 Logging System
JSON-based logging (logs.json)
Tracks suspicious activities and decisions
🚫 Manual Blocking
Custom domain blacklist support
